# 叠数 · 2048

叠数是一个浏览器数字合并小游戏。你在 4×4 棋盘上滑动方块，把相同的数字合在一起，目标是合出 **2048**。

## 启动

双击 `index.html` 即可开始游戏。游戏使用原生 HTML、CSS 和 JavaScript，无需安装依赖或联网。

如果浏览器限制了本地文件的存储权限，可以在项目目录下用 Python 启动本地服务，再访问 `http://127.0.0.1:8000`。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

## 玩法

1. 使用方向键、`W` / `A` / `S` / `D`，或在棋盘上滑动手指。所有方块都会一起向对应方向移动。
2. 相同数字相遇时相加，每个方块在一步内最多参与一次合并。例如，`2、2、2、2` 向左移动会合成 `4、4`，本步加 8 分。
3. 每次有效移动后，空格中会随机出现一个 `2` 或 `4`。棋盘没有发生变化时，步数保持不变。
4. 合出 `2048` 后可以继续挑战。棋盘填满且相邻方块均无法合并时，本局结束。
5. 每局可撤回一步。棋盘、当前分数和步数会一起恢复，最高分保留。点击「新开一局」会重置棋盘和撤回机会。

当前对局和最高分保存在同一浏览器的 `localStorage` 中。清除对应的浏览器数据会重置记录。直接打开 `index.html` 时，存储行为取决于浏览器对本地文件的设置。

## 项目结构

| 文件 | 用途 |
| --- | --- |
| `index.html` | 游戏页面、棋盘和玩法弹窗 |
| `styles.css` | 桌面与手机布局、方块配色 |
| `assets/aurora-arcade.webp` | 霓虹极光背景 |
| `game.js` | 移动、合并、随机方块、撤回和胜负判断 |
| `app.js` | 界面渲染、键盘与触屏输入、本地存档 |
